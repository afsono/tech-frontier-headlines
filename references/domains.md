## 歧义词处理原则

遇到歧义词，**用「技术主体 + 应用场景」双重判断**：

| 歧义词 | 判断依据 | 归属 |
|---|---|---|
| 无人机 | 军用/作战 → 防务；民用/物流/城市交通 → 航空 | 分 |
| 电池 | 储能系统/电站 → 能源；材料研发 → 新材料 | 分 |
| 芯片 | AI 芯片/算力 → 信息；制造设备/工艺 → 信息；半导体材料 → 新材料 | 通常信息 |
| 卫星 | 星座/通信/遥感 → 航天；太空军事 → 防务 | 分 |
| 机器人 | 算法/具身智能 → 先进制造；军用无人系统 → 防务 | 分 |
| 自动驾驶 | 算法与芯片 → 信息；车辆制造 → 先进制造 | 分 |

**拿不准时**：先查两个领域的 feed 看哪边收录了相关条目，以数据源的实际分类为准
（数据源已经用大模型做过分类，比关键词猜测准）。

**更好的做法**：歧义词直接用**话题模式跨领域检索**，不要在某一个领域里猜。

```bash
python scripts/feed.py --keyword 无人机,无人系统,UAV,drone,eVTOL,蜂群
```

实测「无人机」一天在十个领域的分布：防务 26 / 能源 5 / 海洋 4 / 航空 3 /
科技战略 3 / 先进制造 2 / 信息 1 / 航天 1。
**只查"航空"会漏掉 42 条。** 所以歧义词一律跨领域扫，再看分类结果自行分组。

## 话题 ≠ 领域

用户问的可能是**话题**而不是**领域**。区分方法：

| 用户说 | 类型 | 处理 |
|---|---|---|
| "防务""能源""航天" | 领域 | `--domains` |
| "无人机""可控核聚变""英伟达""低空经济""量子计算" | 话题 | `--keyword`，跨领域 |
| "军工""核能""太空" | 领域别名 | 走 ALIASES 映射，`--domains` 会自动识别 |

**判断标准**：能不能对应到十大领域之一？能 → 领域；不能 → 话题。

**话题的额外要求**：检索后按「话题是否为主角」分两组——
标题/分类里就是该话题的算**核心**，仅摘要里提到的算**旁及**，
分组呈现并说明判断依据。详见 SKILL.md 的「话题模式」。


## 用户领域不全在十大领域内怎么办

例：用户说"我关注气候变化"、"我关注金融科技"。

处理：
1. 找最接近的标准领域（气候变化 → 能源 + 海洋；金融科技 → 信息）
2. **明确告知用户这个映射关系**："气候变化我按『能源』和『海洋』两个领域给你抓，这两块最贴近"
3. 如果映射后仍覆盖不到，用联网补充，标注为非本数据源
